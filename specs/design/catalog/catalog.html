コピーの言葉デザイン抑え
コートの熱濃い面 inverse_surface に、ライム secondary の線と display の数字（numeric の細長の数字）を置く熱は 1 画面 1 か所（principles の one-hot-spot）。ライムは score_panel・次のレッスンの日付のコマ・完了の印だけ
次の練習へ次の一手を一番前に置き、主なボタン（button の primary）は 1 画面に 1 つ。空の画面でも次の行動を示す（empty_state の action）次の一手が 2 つ並ぶ画面にしない（principles の next-move-first）
前のめりに太い字（900・700）、詰めた大きな見出し（headline 32px・-0.03em）、-12° の帯、角のあるインクのボタン、動詞で言い切る文言、待たせない動き（motion の fast 120ms・base 200ms）回数・日時・規定・誤りは勢いより正確さを先にする（principles の clear-before-hype）。誤りの知らせに勢いの言葉を使わない

主の色 primary は勢いを担わない。熱は inverse_surface と secondary が担う。primary は押せるもの・リンク・選択中の印で、inverse_surface と同じインク（#0E1013）にする。 青は使わない（0.5.0。人が「往年の Bootstrap 感」と指摘し、案 A「スコアボード」を選んだ 2026-11-05。0.2.0 の落ち着いた青 #3A54B0 から変えた）。 灰は青みを抜いた中立の灰。白地に細い線と、インクと太い数字の差で主役と脇役を分ける

部品

ボタン button・trial

画面の操作を 1 つ実行する（予約する・送る・保存する）

入力欄 text_field・trial

文字を 1 行か数行入れる（表示名・チャットの本文・評価の一言・自己紹介）

日付の欄 date_field・trial

日付を 1 つ、または期間（開始日と終了日）を選ぶ。admin-web の本部とコーチの一覧の絞り込み

選択欄 select・trial

決まった選択肢から 1 つを選ぶ。admin-web の絞り込み（コーチ・レッスンメニュー・スポーツ・キャンセルした人）、本部からのお知らせの対象、コーチのスロットの公開とレッスンメニューの欄（スポーツ・レッスンメニュー・定員）

カード card・trial

1 件のまとまり（予約・コーチ・添削）を囲む

一覧の行 list_row・trial

同じ形のものを並べ、押すと詳細へ移る（お知らせ・スレッド・受けたレッスン）

表 data_table・trial

admin-web で、同じ項目を持つものを列で見比べる（本部の予約・生徒・コーチ・レッスンメニューの一覧など）

ラベルと値の並び description_list・trial

1 件の項目をラベルと値の組で縦に並べる（予約の詳細・コーチの様子・生徒の様子・送る前の確認の中身）。patterns の detail の中身の欄

経緯の並び timeline・trial

1 件に起きた出来事を古い順に縦に並べ、点と線でつなぐ（予約の状態が変わった記録・お知らせの取り下げ・メニューの非公開）

しるし badge・trial

未読の数・未読の小さな印

状態のタグ status_tag・trial

予約・動画添削・スロットの状態を出す（呼び名は glossary の states）

スコアの面 score_panel・trial

画面の主役の数字を 1 つ見せる（ビデオ通話の残り・次のレッスンの日時）

知らせ notice・trial

操作の結果と、読めなかったことを伝える

空の表示 empty_state・trial

一覧や欄に 0 件のとき。背中を押す一言と次の操作を出す

読み込み中 loading・trial

API を読んでいるあいだ

確認のダイアログ confirm_dialog・trial

送る前の確認と、取り消せない操作（予約のキャンセル・受付の停止・メニューの非公開）

入・切の切り替えボタン media_toggle・trial

入室前チェックで、マイク・カメラの入と切、試し音の「鳴らす⇄止める」を切り替える

カメラの映りの枠 camera_preview・trial

入室前チェックで、本物のカメラの映りと背景を見せる。許可待ち・切・使えない・ないも同じ枠で示す

音の大きさの表示 level_meter・trial

入室前チェックで、マイクに届いた声の大きさを見せる

入室の帯 join_bar・trial

入室前チェックで、開始時刻・残り時間・入室の条件と「入室する」を画面の下に固定する（patterns の detail の「下に固定」の形）
