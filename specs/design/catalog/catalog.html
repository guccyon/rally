コピーの言葉デザイン抑え
コートの熱濃い面 inverse_surface に、ライム secondary の線と display の数字を置く熱は 1 画面 1 か所（principles の one-hot-spot）
次の練習へ次の一手を一番前に置き、主なボタン（button の primary）は 1 画面に 1 つ。空の画面でも次の行動を示す（empty_state の action）次の一手が 2 つ並ぶ画面にしない（principles の next-move-first）
前のめりに太い字（900・700）、-12° の帯、動詞で言い切るボタン、待たせない動き（motion の fast 120ms・base 200ms）回数・日時・規定・誤りは勢いより正確さを先にする（principles の clear-before-hype）。誤りの知らせに勢いの言葉を使わない

主の色 primary は勢いを担わない。熱は inverse_surface と secondary が担い、primary は押せるもの・選択中の印として落ち着いた青（#3A54B0）にする（0.2.0。人が「青が強い」と指摘）

部品

ボタン button・trial

画面の操作を 1 つ実行する（予約する・送る・保存する）

入力欄 text_field・trial

文字を 1 行か数行入れる（表示名・チャットの本文・評価の一言・自己紹介）

カード card・trial

1 件のまとまり（予約・コーチ・添削）を面で囲む

一覧の行 list_row・trial

同じ形のものを並べ、押すと詳細へ移る（お知らせ・スレッド・受けたレッスン・admin-web の一覧）

しるし badge・trial

未読の数・状態の小さな印

状態のタグ status_tag・trial

予約・動画添削・スロットの状態を出す（呼び名は glossary の states）

スコアの面 score_panel・trial

画面の主役の数字を 1 つ見せる（今月のビデオ通話の残り・次のレッスンの日時）

知らせ notice・trial

操作の結果と、欄が読めなかったことを伝える

空の表示 empty_state・trial

一覧や欄に 0 件のとき。背中を押す一言と次の操作を出す

読み込み中 loading・trial

API を読んでいるあいだ

確認のダイアログ confirm_dialog・trial

送る前の確認と、取り消せない操作（予約のキャンセル・受付の停止・メニューの非公開）
