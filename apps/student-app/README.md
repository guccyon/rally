# student-app

Rally の生徒アプリの最小（Flutter stable・null safety・`flutter_lints`・状態管理は Riverpod）。Gen1 の一周シナリオの生徒側を通す。iOS / Android の実機ビルドは P0〜P1 の対象外なので、確認は `flutter analyze` と `flutter test` まで（`ios/` `android/` はまだ置かない）。

## コマンド

```sh
flutter pub get
flutter analyze   # 警告 0
flutter test      # ウィジェットテスト（API はモック）と一周テスト
flutter run --dart-define=RALLY_API_URL=http://127.0.0.1:8080   # 接続先（既定はバックエンドの既定の待ち受け）
```

## 画面

画面遷移は状態（`lib/state/student_flow.dart` の `FlowStep`）だけで決まる。API を呼ぶのは `lib/state/` の Notifier だけで、画面は状態を表示してそのメソッドを呼ぶ。チャット（スレッドの一覧・メッセージ・添削の依頼と返却）の状態と操作は `lib/state/chat.dart` の `ChatState` / `ChatNotifier`（`chatProvider`）、完了したレッスンの評価（この端末で送った評価・評価済みと分かっているレッスン）の状態と操作は `lib/state/lesson_review.dart` の `LessonReviewState` / `LessonReviewNotifier`（`lessonReviewProvider`）、月額契約と受講権（契約プランの一覧・この端末で始めた契約・受講権と、受講権がまだないこと）の状態と操作は `lib/state/subscription.dart` の `SubscriptionState` / `SubscriptionNotifier`（`subscriptionProvider`。ホームの「今月のビデオ通話」の欄と自分の予約のキャンセルの確認もここの受講権を読む）、コーチを探す画面（生徒のスポーツのコーチの一覧と、読めなかったこと）の状態と操作は `lib/state/coach_search.dart` の `CoachSearchState` / `CoachSearchNotifier`（`coachSearchProvider`）、コーチの紹介（選んだコーチ・欄ごとの読んだ値と、読めなかった欄）の状態と操作は `lib/state/coach_profile.dart` の `CoachProfileState` / `CoachProfileNotifier`（`coachProfileProvider`）、それ以外は `StudentFlowState` / `StudentFlowNotifier`（`studentFlowProvider`）に置く。段（`FlowStep`）と、API を呼んでいる間の印（`busy`）・直前の操作の失敗の文言（`errorMessage`）はアプリで 1 つなので `StudentFlowState` に持ち、`ChatNotifier` と `LessonReviewNotifier` と `SubscriptionNotifier` と `CoachSearchNotifier` と `CoachProfileNotifier` も段の移動は `StudentFlowNotifier.moveTo`、API の呼び出しは `StudentFlowNotifier.run` を通す。評価する完了したレッスン（`lesson`）は完了記録の結果なので `StudentFlowState` に残す。契約するスポーツは登録した生徒（`student`）のものなので `StudentFlowState` から読み、ホームで読めなかった欄（`homeFailures`）もホームの全体の状態として `StudentFlowState` に残す。

## API

- 契約 `specs/contracts/api/student-app/openapi.yaml` のスキーマを `lib/api/models.dart` に手で写した（ジェネレーターは Java が要るので使っていない）。型名は契約のスキーマ名に揃え、項目名は lowerCamelCase にする。契約の `Error` だけは Dart の `Error` と衝突するので `ApiError`
- 操作は `lib/api/student_api.dart` の `StudentApi`（operationId と 1 対 1）、HTTP の実装は `lib/api/http_student_api.dart`。契約の `ErrorCode` → 画面の文言は `lib/api/error_message.dart` の 1 か所（`Error.message` は表示用ではないので出さない。表示名の変更の 422 だけは例外としてサーバーの文言を出す）
- 契約の enum とのずれ・操作の有無は `test/api/contract_test.dart` が検出する。契約を変えたら `models.dart` を合わせる
