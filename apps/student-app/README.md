# student-app

Rally の生徒アプリの最小（Flutter stable・null safety・`flutter_lints`・状態管理は Riverpod）。Gen1 の一周シナリオの生徒側を通す。iOS / Android の実機ビルドは P0〜P1 の対象外なので、確認は `flutter analyze` と `flutter test` まで（`ios/` `android/` はまだ置かない）。

## コマンド

```sh
flutter pub get
flutter analyze   # 警告 0
flutter test      # ウィジェットテスト（API はモック）と一周テスト
flutter run --dart-define=RALLY_API_URL=http://127.0.0.1:8080   # 接続先（既定はバックエンドの既定の待ち受け）
```

## 画面

画面遷移は状態（`lib/state/student_flow.dart` の `FlowStep`）だけで決まる。API を呼ぶのは `StudentFlowNotifier` だけで、画面は状態を表示してそのメソッドを呼ぶ。

| 画面（`lib/screens/`） | 呼ぶ操作 |
|---|---|
| アカウント登録（登録したらホームへ） | `registerAccount`（続けてホームの欄を読む） |
| ホーム（登録後に最初に開く。ほかの画面からはアプリバーの「ホーム」で戻り、開くたびに欄を読み直す）: これからの予約（キャンセル済みと始まった予約を除き、開始の近い順に 3 件まで。各行はスポーツ・予約した時点のレッスンメニュー（あれば。書き方はスロットを探す画面の枠と同じ）・コーチの名前・状態を「・」でつなぐ。「予約をすべて見る」で自分の予約、「スロットを探して予約する」で生徒のスポーツのスロット検索）・今月のビデオ通話（「月 N 回のうち残り M 回」とプラン。受講権の 404 は月額契約の前として「まだ月額契約はありません」）・コーチとのやり取り（未読のあるスレッドと、最後のメッセージが添削の依頼か返却のスレッドを新しい順に。押すとそのチャットを開き、閉じるとホームに戻る。コーチの名前は自分の予約に載っているものを使い、なければ「担当コーチ」）・「添削を依頼する」（スレッドが 1 つならそのチャットを開いてすぐに添削の依頼を出し、2 つ以上ならスレッドの一覧を開く。スレッドがなければ押せない）。欄ごとに別の API を読み、どれかが失敗しても他の欄は出して、その欄にだけ読めなかった旨を出す。0 件の欄は「まだ〜はありません」 | `listMyBookings` / `getMyEntitlement` / `listMessageThreads` |
| スロットを探す（スポーツで絞る。各行は縦に 日時（例: `10/28（水）3:00〜4:00`）→ スポーツ → グループレッスンの枠（定員 2 以上）なら「グループ（定員 N 人・残り M 席）」（定員 1 の枠には出さない）→ 枠にレッスンメニューが結びついていればメニューの名前と 1 回の時間（例: `メニュー: フォアハンドの基礎（1 回 60 分）`。時間が null なら名前だけ。メニューのない枠には出さない）→ 載っていればコーチの名前と自己紹介文 → コーチの評価の件数と平均（例: `★ 4.2（12 件）`。0 件なら「評価はまだありません」）→ 行の幅いっぱいの「体験予約する」。自己紹介文は 2 行までで、収まらなければ「続きを読む」で全文。評価は「評価を見る」でそのコーチの詳細を開き、そのコーチの公開中のレッスンメニューのうち生徒のスポーツのもの（作った順。名前 → スポーツ・同期 / 非同期 → 同期なら「1 回 N 分」→ 説明。なければ「まだメニューがありません」）と、評価の一覧（新しい順。点・一言・送った時刻）を出す。評価が 0 件か件数と平均を読めなかったコーチは「メニューを見る」でメニューだけを開く。評価・メニューの API が失敗しても検索結果と体験予約とほかの欄はそのままで、その欄にだけ読み込めなかった旨を出す）・体験予約 | `searchSlots`（続けて検索結果のコーチごとに `getCoachReviewSummary`）/ `listCoachReviews` / `listCoachLessonMenus`（`sport` は生徒のスポーツ）/ `createBooking`（`is_trial: true`） |
| 予約の確定待ち（確定後に通話か動画の送付を選ぶ。予約した枠にレッスンメニューが結びついていれば、確定の前後ともスロットを探す画面と同じ形でメニューの名前と 1 回の時間を出す） | `confirmBooking` |
| ビデオ通話（開始・終了のボタンだけ。映像はモック） | `startLiveLessonSession` / `endLiveLessonSession` |
| 動画を送る（ファイルの選択と本体のアップロードはモック。送り先は体験予約のコーチ、スポーツはそのスロットのもの） | `submitVideo` |
| 添削結果（未返却なら確かめ直す。AI の一次フィードバック `ai_feedback` があれば、未返却でも返却後でも「AI の一次フィードバック」として、AI が自動で作った文でコーチの添削ではない旨と一緒に、コーチの添削とは別の枠に出す。ないときは出さない） | `getVideoReview` |
| レッスンの完了 | `recordLessonCompletion`（通話なら `live_lesson`、動画なら `async_lesson`） |
| レッスンの評価（完了のあとに 1〜5 の点と一言。評価済みを返す読み取りの API はないので、この端末で送れたときと 409 `lesson_already_reviewed` が返ったときに評価済みとして入力させない。評価せずに月額契約へ進むこともできる） | `submitLessonReview` |
| 月額契約（プランをスタンダード「ビデオ通話 月 2 回」とプラス「ビデオ通話 月 4 回」から選ぶ。既定はスタンダードで、選んだプランを `plan` で送る。選ぶ前の回数の案内は `lib/ui/labels.dart` に持ち、開始後はプランと、今月のビデオ通話を応答の `live_lesson_quota` から「月 N 回のうち残り M 回」で出す。決済はモック。`payment_method_token` は固定のモック値） | `startSubscription` |
| チャット: 担当コーチとのスレッドの一覧（未読の数・最後のメッセージ。登録後はどの画面からもアプリバーの「チャット」で開き、閉じると開いた画面に戻る） | `listMessageThreads` |
| チャット: メッセージ（送った順。自分が送ったものに既読・未読。開いたときと確かめ直したときに相手のメッセージを既読にする）と送信（月額契約の前は 403 `chat_not_entitled` の文言）。入力欄のそばの「添削を依頼する」で動画を選んで（モック）送ると添削の依頼になる（一周シナリオの動画の送付と同じ `submitVideo`。送り先はスレッドの担当コーチ、スポーツは生徒のもの。普通のメッセージとして動画は送れない）。入力欄のそばの「スタンプ」で 8 種類（絵文字と短い言葉。例 🙏 ありがとう。絵文字と言葉は `lib/ui/labels.dart`）から選ぶと、本文の代わりにそのスタンプを送る（`sendMessage` の `stamp_id`。受講権の扱いは本文と同じ）。種類 `kind` がスタンプのメッセージは、本文より大きな絵文字に言葉を添えて吹き出しなしで出す（このアプリの版が知らない ID のスタンプは `body` の説明を本文として出す。スレッドの一覧とホームの最後のメッセージは `body` の説明のまま）。種類 `kind` が添削の依頼・返却のメッセージは、本文の吹き出しと見分けられるアイコンと見出し付きのカードで時間の順に出す（依頼は「N 回目の添削の依頼」、返却は「コーチの添削（N 回目の依頼）」とコーチの添削の本文、AI の一次フィードバックがあれば別の枠。返却の添削は動画ごとに `getVideoReview` で読み、読めなければそのカードにだけ旨を出して確かめ直したときに読み直す）。知らない種類のメッセージは隠さず `body` を本文として出す（スレッドの一覧の最後のメッセージも同じ） | `listMessages` / `markMessageThreadRead` / `sendMessage` / `submitVideo` / `getVideoReview` |
| 通知の受け取り設定（予約の確定・添削の返却・メッセージの受信の種類ごとのスイッチ。登録後はどの画面からもアプリバーの「通知の設定」で開き、閉じると開いた画面に戻る。切り替えたらその種類だけをすぐ保存し、失敗したら元に戻して文言を出す） | `getMyNotificationSettings` / `updateMyNotificationSettings` |
| 自分の予約（登録後はどの画面からもアプリバーの「自分の予約」で開き、閉じると開いた画面に戻る。キャンセル済みも含めて、日時・スポーツ・予約した時点のレッスンメニューの名前と 1 回の時間（`Booking.lesson_menu`。例: `メニュー: フォアハンドの基礎（1 回 60 分）`。時間が null なら名前だけ。メニューのない予約には出さない）・載っていればコーチの名前・状態を出す。まだ始まっていない予約（キャンセル済みを除く）には「この予約をキャンセルする」を出し、押すと確認する。月額契約の生徒が開始 24 時間前以降にキャンセルするときは「今キャンセルすると、今月のビデオ通話の回数を 1 回使います。」と添える（回数を使うかを決めるのはサーバーで、ここは同じ境界で確認の文言を出すだけ。今の時刻は `clockProvider` で、テストでは固定する）。キャンセルできたらその予約をキャンセル済みにし、失敗したら状態を変えずに文言を出す） | `listMyBookings` / `cancelBooking` |

## API

- 契約 `specs/contracts/api/student-app/openapi.yaml` のスキーマを `lib/api/models.dart` に手で写した（ジェネレーターは Java が要るので使っていない）。型名は契約のスキーマ名に揃え、項目名は lowerCamelCase にする。契約の `Error` だけは Dart の `Error` と衝突するので `ApiError`
- 操作は `lib/api/student_api.dart` の `StudentApi`（operationId と 1 対 1）、HTTP の実装は `lib/api/http_student_api.dart`。契約の `ErrorCode` → 画面の文言は `lib/api/error_message.dart` の 1 か所
- 契約の enum とのずれ・操作の有無は `test/api/contract_test.dart` が検出する。契約を変えたら `models.dart` を合わせる
