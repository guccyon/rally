### 追加
- 本部がコーチを登録する: admin-web の `POST /coaches`（`registerCoach`）を実装した。本部だけが、メールアドレス・表示名・提供スポーツ（1 つ以上）を送ってコーチのアカウントを作れる（コーチ・生徒は 403、同じメールアドレスは 409 `email_already_registered`、不正な入力は 422）。登録したコーチはそのまま `listCoaches` に載り、提供スポーツのレッスンメニューを作れる。本番の空の DB からコーチを API で登録できるようにするため。DB の変更はない（#1579）
- 本部のアカウントを作る運用コマンド: backend のイメージに `headquarters-account --email <メールアドレス> --display-name <表示名>` を足した。本部のアカウントを 1 つ作ってアカウント ID を標準出力に書き、同じメールアドレスの本部がすでにあれば何もせずその ID を書く（何度実行してもよい）。本番の空の DB の最初の本部を作るため（#1579）
