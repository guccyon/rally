### 追加
- 本部が予約 1 件の詳細でキャンセルの経緯を読める契約にした: admin-web の `GET /bookings/{booking_id}`（`getBooking`）の状態が変わった記録 `BookingStatusChange` のキャンセルの記録に、任意の欄 キャンセルした人 `cancelled_by`・回数を消費したか `consumes_quota`・開始の何時間前か `hours_before_start`・キャンセルの理由 `cancel_reason`（新しい `BookingCancelReason`。今は `coach_leave` だけ）・そのお休みの記録 `coach_leave`（`CoachLeave`。期間・操作した本部のアカウント・時刻）を足した。「キャンセルされた予約」の一覧（`GET /bookings/cancelled`。`listCancelledBookings`）の `CancelledBooking` にも `cancel_reason` を足した。CS が「予約が消えた」という問い合わせに DB を見ずに答えるため。記録のないキャンセルは null で、足した欄はすべて任意か null 可（既存の利用者はそのまま）。境界間イベント `BookingCancelled` と DB は変えない（#1029）
